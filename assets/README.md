# NatureLet 素材说明

网页里的图片和视频统一放在这里，方便后期替换。

## images

- `hero-person-phone.jpg`：首页首屏背景图，也是视频播放器的封面图。
- `flower-rose.jpg`：手机识别演示图，以及真实图库里的花卉图。
- `bird-kingfisher.jpg`：真实图库里的鸟类图。
- `fish-clownfish.jpg`：真实图库里的鱼类图。
- `insect-butterfly.jpg`：真实图库里的昆虫图，也是小程序引导区背景图。

## videos

- `person-phone-nature.mp4`：人物场景视频。

## 替换方式

如果不想改网页代码，直接用新的素材覆盖同名文件即可。建议保持图片为 `.jpg`，视频为 `.mp4`；如果文件名或格式变化，再同步修改 `index.html` 和 `style.css` 里的路径。
